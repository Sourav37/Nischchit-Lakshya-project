# Workshop Schedule Configuration

Edit the values below to set your future workshop date and time.
The countdown timer, hero section, floating pill, and details cards will update automatically!

---

## 📅 Workshop Schedule Settings

- **DATE**: 2026-09-21
- **TIME**: 08:09 PM
- **TIMEZONE**: IST

---

### Optional Custom Overrides (leave blank or remove to use defaults)

- **DATE_DISPLAY**: 21 Sep 2026
- **COUNTDOWN_TITLE**: Next Live Batch Starts {day} at {time}

---

### 📝 Guide for Developers & Organizers:
1. **DATE**: Future date in `YYYY-MM-DD` format (e.g. `2026-09-21`).
2. **TIME**: 12-hour format with AM/PM (e.g. `08:09 PM`, `10:00 AM`) or 24-hour format (e.g. `20:09`).
3. **TIMEZONE**: Timezone label shown to students (e.g. `IST`, `EST`, `UTC`). Default is `IST`.
4. **DATE_DISPLAY**: Custom text shown in the DATE card on the website (e.g. `21 Sep 2026` or `Upcoming Batch`).
5. **COUNTDOWN_TITLE**: Custom template for hero countdown. Supports `{day}`, `{time}`, `{timezone}` placeholders.
